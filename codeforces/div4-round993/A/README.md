## Đề bài (tóm tắt)

Đếm số cặp `(a, b)` số nguyên dương thoả `a + b = n`. Đáp án là `n - 1`.

## Ý tưởng

In `n - 1`.

## Độ phức tạp

- Thời gian: `O(1)`
- Bộ nhớ: `O(1)`

## Bài học
